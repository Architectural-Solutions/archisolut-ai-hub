# Flujo del conocimiento — referencia operativa

## Buscar antes de crear

Consulta síntomas, nombre aproximado, sinónimos y etiquetas disponibles. Lee notas encontradas, comprueba autoría/estado y sigue relaciones existentes. Cita lo efectivamente leído. Si el buscador no indexa Markdown o devuelve solo archivos visibles, reconoce cobertura parcial.

## Cuándo proponer una nota

Si se resolvió un problema no trivial, se creó una herramienta reutilizable, se decidió entre alternativas o se definió un proceso. No documentes cada interacción ni compartas información privada por defecto.

## Clasificación

La taxonomía actual se obtiene en el Vault; no copies valores antiguos sin verificar. Separar:
- `idea`: propuesta por evaluar.
- `investigacion`: diagnóstico o análisis sin solución demostrada.
- `aprendizaje`: solución verificada que otro puede reproducir.
- `desarrollo`: implementación / artefacto técnico.
- `decision`: decisión documentada y alternativas.

Consulta ruta temática y metadatos de la guía vigente. `[[wikilinks]]` solo a notas existentes. La nota creada por IA nace `origen: ia`, `status: borrador`; nunca promover a `activo` automáticamente.

## Estructura recomendada para aprendizajes

- Síntomas / problema.
- Contexto y versiones relevantes.
- Causa confirmada, probable o desconocida.
- Solución ejecutada (diferente de propuesta).
- Pruebas y resultado, con fuente y quién validó.
- Cuándo reutilizar, cuándo no y cautelas.
- Enlaces y referencias reales.
- Pendientes.

## Publicación

Solo mediante identidad y permisos verificados, consentimiento y operación de creación no sobrescritora. Si falta una garantía, devolver nota Markdown propuesta para revisión humana, nunca simular subida ni forzar acceso.
