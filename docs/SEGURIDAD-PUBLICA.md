# Reglas de publicación pública de AI Hub

La distribución está pensada para un repositorio **público**. No publicar ningún documento interno copiado del Vault ni exportaciones de Notion, archivos `.env`, tokens, correos privados, datos personales, registros internos, nombres de clientes ni mecanismos para ampliar privilegios.

La URL de un recurso restringido no concede acceso. Su publicación deberá evaluarse para minimizar metadatos expuestos. Este paquete solo referencia páginas protegidas relacionadas directamente con las reglas necesarias de incorporación y desarrollo. No contiene documentación interna descargada.

Antes de hacer push: revisión de diff y contenido, escaneo de secretos, verificación de licencias de material de terceros y validación de los enlaces. El cambio se publica exclusivamente por el responsable autorizado con revisión y aprobación. La automatización de Git/despliegues queda fuera del alcance de esta versión.
